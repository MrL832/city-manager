# Ethics & Impact Simulator

## Overview

This project is a React web app designed to support revision for **AQA GCSE Computer Science**.

The app presents students with a **smart city decision-making simulator** in which they act as the mayor of a city using digital technology. They are asked to make decisions about privacy, security, safety, legality, and environmental impact, then review the consequences of those decisions.

The aim is not to tell students that one answer is always "correct". Instead, the simulator helps them understand that many technology issues involve **trade-offs** and that strong GCSE answers should explain **both sides of an argument**.

## Intended Audience

This app is suitable for:

- GCSE Computer Science students revising ethical, legal, and environmental impacts of technology
- Teachers looking for an interactive classroom or homework resource
- Tutors supporting exam-style discussion and paragraph writing

## Curriculum Relevance

The simulator is built around topics that match the AQA GCSE Computer Science specification, especially the impacts and risks of digital technology.

The scenarios cover:

- Wearable technology and health data sharing
- Autonomous vehicles and liability
- Cyber security, hacking, and critical systems
- Cloud storage and wireless networking
- Biometrics and implants

The legal content includes specific references to:

- **Data Protection Act 2018**
- **UK GDPR**
- **Computer Misuse Act 1990**

## How The App Works

Students work through five scenarios.

For each scenario, they:

1. Read a realistic smart city dilemma
2. Choose a policy decision
3. Review the consequences using impact cards
4. Explore the ethical, legal, and environmental issues
5. Use exam sentence starters and revision prompts

At the end of the simulator, students receive:

- A final comparison screen
- A score breakdown chart
- A topic-by-topic review
- A model final paragraph
- A printable revision sheet

## Teaching Value

This app can be used to support:

- Retrieval practice
- Classroom discussion
- Homework revision
- Independent study
- Exam paragraph planning

It is especially useful for helping students move beyond simple one-sided answers such as "technology is good" or "technology is bad".

## Running The Project

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```

Run lint checks:

```bash
npm run lint
```

## Tech Stack

- React
- Vite
- Tailwind CSS

## Notes For Teachers

- The app is designed to support explanation and discussion rather than simple quiz scoring.
- Students can print or save the final revision sheet as a PDF.
- The simulator encourages balanced judgement, which is useful for longer-mark GCSE responses.

## Project Purpose

This project was created to make revision more interactive and to help students practise explaining how digital technologies affect people, organisations, and society.
